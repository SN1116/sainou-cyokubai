GitHub Pages 設置手順ガイド

このサイトは GitHub Pages で即時公開可能です！

以下のステップで設定を行ってください。

1

GitHub にリポジトリを作成し `index.html` として保存

このコード全体を `index.html` という名前で保存して GitHub リポジトリにプッシュします。

2

Firebase Console で「Google ログイン」を有効化

Firebase Console ＞ Authentication ＞ Sign-in method ＞ 「Google」を有効化します。

3

Firebase に GitHub Pages のドメインを許可追加

Authentication ＞ 設定 ＞ 「承認済みドメイン (Authorized domains)」 に GitHub Pages の URL（例: username.github.io）を追加してください。

4

Firestore のデータベースルールを適用

Firestore ＞ ルール で feedbacks コレクションへの書き込み権限を有効化します。
